# 다선일미 (茶禪一味)

> 차 한 잔으로 마음을 돌아보는 iOS 명상 앱

고민을 적고, 차를 준비하고, 우리고, 따르고, 마시는 과정을 통해 마음을 천천히 돌아보는 차 명상 앱입니다.
사용자의 고민을 번뇌 유형으로 분류해 어울리는 차와 명언을 추천하고, 스마트폰의 모션 센서로 실제로 차를 따르고 마시는 듯한 몰입형 인터랙션을 제공합니다.

'다선일미(茶禪一味)'는 차와 선(禪)이 한 맛이라는 뜻입니다.

## 담당 역할

### 1. 모션 센서 기반 인터랙션

스마트폰의 움직임을 차를 따르고 마시는 경험으로 연결하는 센서 기능을 중심으로 담당했습니다.

- `expo-sensors`로 기기의 기울기와 회전 감지
- Quaternion 기반 기기 자세 계산과 화면 방향 보정
- 센서 노이즈를 줄이기 위한 필터링
- 화면에 들어올 때 현재 자세를 기준으로 baseline 재보정
- 기울기 각도로 차 따르기 동작 판정
- 휴대폰을 들어 올리는 움직임으로 차 마시기 동작 판정
- Threshold, hold, cooldown으로 오작동과 중복 감지 방지
- Reanimated `SharedValue`로 센서 데이터와 UI 애니메이션 연결
- 실제 iPhone에서 센서 동작 검증 및 수치 튜닝

### 2. 차 체험 UI 및 플로우

- 차 추천 및 선택 화면
- 찻잎을 다관에 넣는 애니메이션
- 차 따르기·마시기 화면 UI
- 차 종류에 따른 이미지, 액체 색상, 발광 효과
- 차 준비부터 명상 화면까지 이어지는 화면 연결
- Figma 레이어 구조를 기반으로 한 애니메이션 구현
- 단위 테스트 및 iPhone 실기기 통합 테스트

## 구현 포인트

### 기기 자세 계산

- 센서 값을 Quaternion으로 받아 기기 자세를 계산하고, 화면 방향에 맞게 축을 보정했습니다.
- 오일러 각보다 회전을 안정적으로 다룰 수 있어, 폰을 잡는 방향이 달라도 같은 기준으로 기울기를 계산할 수 있습니다.

### 오작동 방지

센서 값은 가만히 들고 있어도 계속 조금씩 흔들리기 때문에, 처음부터 노이즈와 중복 감지를 막는 구조로 설계했습니다.

- **필터링:** 센서 노이즈를 줄여 작은 떨림에 반응하지 않게 했습니다.
- **Threshold:** 일정 각도 이상 기울였을 때만 동작으로 인정합니다.
- **Hold:** 그 각도를 일정 시간 유지해야 인정합니다.
- **Cooldown:** 한 번 감지한 뒤 일정 시간 동안은 다시 감지하지 않습니다.

### 센서와 애니메이션 연결

- 센서 값을 Reanimated `SharedValue`로 관리해, 값이 바뀔 때마다 React 리렌더링 없이 UI 스레드에서 애니메이션과 바로 연결했습니다.

## 문제 해결

### 사용자마다 폰을 드는 자세가 다른 문제

- **문제:** 처음에는 고정된 기준 각도로 따르기·마시기를 판정했습니다. 그런데 사람마다 폰을 드는 자세가 달라서, 폰을 눕혀 드는 사람은 조금만 움직여도 따르기가 시작되고, 세워 드는 사람은 한참 기울여야 인식됐습니다.
- **원인:** 판정 기준이 기기의 절대 각도라서, 시작 자세가 다르면 같은 동작도 다른 값으로 계산됐습니다.
- **해결:** 차 따르기·마시기 화면에 들어오는 순간의 자세를 baseline으로 저장하고, 그 자세에서 얼마나 움직였는지로 판정하도록 바꿨습니다.
- **결과:** 시작 자세와 관계없이, 같은 크기로 움직이면 같은 동작으로 인식되도록 개선했습니다.

## 주요 기능

- 사용자의 고민을 바탕으로 번뇌 유형 분류
- 번뇌 유형과 시간대에 따른 차 추천
- 차 준비·우리기·따르기·마시기로 이어지는 체험형 플로우
- 스마트폰 기울기를 활용한 차 따르기·마시기 인터랙션
- 체험 종료 후 명언 추천과 개인 기록 저장
- Supabase를 활용한 실시간 풍등 피드

## 사용자 흐름

```text
고민 작성
→ 풍등 체험
→ 오늘의 차 추천 및 선택
→ 차 준비 → 차 우리기 → 차 따르기 → 차 마시기
→ 명상 및 명언
→ 기록 저장
```

## 실행 방법

### 1. 의존성 설치

```bash
npm ci
```

### 2. 환경변수 설정

프로젝트 루트에 `.env` 파일을 만들고 Supabase 정보를 넣습니다.

```bash
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. 개발 서버 실행

```bash
npx expo start
```

> 센서 기능은 iOS 시뮬레이터에서 동작하지 않습니다. 실제 iPhone의 Expo Go에서 확인해 주세요.
